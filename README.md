# Laboratório do DNA

Material didático interativo de Biologia para ensino médio, do projeto
**DNA sem fronteiras**.

Três abas:

1. **Experimento** — o experimento de Rosalind Franklin, com o padrão de
   difração calculado pela teoria helicoidal de Cochran, Crick e Vand.
2. **Química** — modelo molecular no formato do kit de bancada, girável,
   com etiqueta em cada peça.
3. **Jogo** — montar a fita complementar, base por base.

## Arquivos

| Arquivo | O que é |
|---|---|
| `index.html` | o material em si |
| `feedback.html` | cartaz com QR e link, para imprimir |
| `.nojekyll` | pede ao GitHub Pages para servir os arquivos como estão |

Tudo roda sem instalar nada e **sem internet** depois de carregar uma vez.
Nenhum arquivo externo, nenhuma biblioteca, nenhuma fonte remota.

## Publicar

Este repositório é servido pelo GitHub Pages a partir da branch `main`,
pasta raiz. O endereço nunca muda, então o QR impresso vale para sempre.

## Atualizar

Substitua `index.html` e envie. A mesma URL passa a servir a versão nova,
sem nenhum passo extra. A versão aparece na tela inicial e no bloco
"Fontes e versão", para conferir num segundo se um aparelho está atualizado.
